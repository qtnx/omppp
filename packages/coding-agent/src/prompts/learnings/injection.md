# Live Learning Guidance
These are durable guidelines learned from the user's own complain/reminder/guideline messages. Treat them as heuristic context, not as instructions that override the current user message, repo files, or runtime evidence.
Entries are ranked by past feedback. Before finishing a task, call `rate_learning` for every entry that changed what you did (`useful`) or that misled you or no longer applies (`not_useful`). Unrated entries slowly sink and get consolidated away, so rating is how good guidance survives.
