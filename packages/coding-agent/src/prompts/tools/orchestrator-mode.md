Switch or inspect Safe orchestrator mode.

Operations:
- `enter`: enable Safe orchestrator mode. The parent session switches to the safe orchestration toolset plus this control tool.
- `exit`: leave Safe orchestrator mode. The parent session restores the toolset that was active before entry.
- `status`: report whether Safe orchestrator mode is active without changing tools.

Use this tool when you need to enter orchestration-only work, confirm the current mode, or return to normal tool access.
