already-in-brief: the message explicitly says the fact/anchor/check is already supplied in the brief, or asks whether to rediscover that supplied information. A question mark does not turn this into a design decision.
fact-in-repo: a missing fact the parent can recover from repository code, anchors, or a known contract.
decision: a genuinely unresolved design or scope choice for the parent, not re-confirmation of a supplied fact.
user-only: unavailable user-held information, credentials, external access or mandatory approval, with no permitted parent-side source.
