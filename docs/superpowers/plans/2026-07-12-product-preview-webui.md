# Product Preview WebUI — Implementation Plan (DRAFT — pending approval of the dogfood spec/design/architecture artifacts)

**Goal:** Local web UI presenting product artifacts (docs/product/** by default, general roots supported) with live reload, annotate-overlay feedback, side-ask channel into the owner agent session, agent-invokable `present` tool, CLI + slash entry points, and human-gated Tailscale share with token auth + teammate pull handoff.

**Architecture:** One in-process module `packages/coding-agent/src/product-preview/` (Bun.serve, 127.0.0.1 default). Zero-build client (text imports; marked+dompurify+mermaid embedded from pinned deps). SSE live reload (mtime+size poll, 500ms settle, 15s heartbeat). Feedback via existing annotate overlay + POST /api/side-ask → ToolSession.queueBrowserAnnotation (untrusted envelope, sanitized). Share = separate module minting tokens; enabling share requires a human keystroke (slash/CLI), never the agent tool.

**Tech:** Bun.serve, marked, dompurify, mermaid (all pinned, embedded via `with {type:"text"}` from node_modules dist bundles), Bun.Archive for export tar.gz.

## Global constraints
- AGENTS.md rules: no console.log (logger only), ES #private, Promise.withResolvers, namespace node imports, no ReturnType<>, no inline imports, prompts in .md files.
- All routes: `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`, zero CORS headers, Host-header allowlist BEFORE auth (127.0.0.1:<port>, localhost:<port>, <ts-ip>:<port> → else 403), loopback checks use socket peer address only (ignore X-Forwarded-For).
- Auth: share token 128-bit CSPRNG base64url; timingSafeEqual comparisons; `?t=` exchanged once → HttpOnly SameSite=Strict cookie (independent CSPRNG sid, server map records minted-for Host; cookie honored only on matching Host) → 302 strips query. Bearer stays for curl. Uniform 401; per-IP 401 throttle. Share off / re-enable → rotate: revoke token + sessions + drop SSE.
- Export: single-use export tokens, 15-min TTL; handoff command uses env-var form (`OMPX_ET=… curl -H "Authorization: Bearer $OMPX_ET"`), fresh dest dir `docs/product-shared/<bundle-id>/`, `tar -xz --no-same-owner`, untrusted-content instructions.
- Mockups: `/mockup/<id>` = framed shell (iframe sandbox="allow-scripts", no allow-top-navigation); `/mockup-raw/<id>` = loopback-only 403-otherwise, CSP `sandbox allow-scripts; default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data:; form-action 'none'` (owner annotate rects route). Markdown views CSP `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'; form-action 'none'; base-uri 'none'`; marked → DOMPurify → mermaid init.
- Side-ask: POST /api/side-ask requires header `X-OMPX-Preview: 1` always + auth (cookie or loopback); 6/min/IP; 10k cap; comment sanitized (angle-bracket envelope-delimiter escaping) before wrapping in the browser-annotation untrusted envelope; label `[side-ask from <peer> via shared preview]`.
- Share enable: slash `/product-preview share on` or CLI `--share` ONLY. `present(share:true)` → error directing to the slash command. Funnel check (`tailscale funnel status` best-effort) at enable; refuse if funnel serves our port; warn if CLI missing. Tailscale bind: interface in 100.64.0.0/10 via os.networkInterfaces(), fallback `tailscale ip -4`; no interface → refuse (never 0.0.0.0). Token/URL printed to TUI only; model sees redacted result.

## Amendments (execution evidence)
**A1 (P2 runtime evidence, 2026-07-12) — share listener topology.** The local server always binds `127.0.0.1` (owner; `localUrl` unchanged). `enableShare()` starts a SECOND `Bun.serve` bound explicitly to the resolved Tailscale IP, sharing the SAME fetch handler (auth, Host allowlist, per-route CSP, side-ask). `disableShare()` stops that second listener. NEVER `0.0.0.0`. Consistent with the locked ledger — the Host allowlist already lists `<ts-ip>:port`. Bun cannot rebind a running listener, so two explicit-bind listeners is the only owner-keeps-127 + tailnet-reachable option that never uses `0.0.0.0`.

**A3 (codemc access) — hostname Host alias.** `ShareInfo` gains additive `readonly hostAliases?: readonly string[]`; the controller advertises the validated, lowercased machine hostname (bare-DNS regex — no port/wildcard/scheme). At enable-commit the server copies `host` + each re-validated alias into a private immutable `#shareHostAuthorities` set and `#isAllowedHost` checks membership; cleared on disable/stop/bind-failure so a returned ShareInfo can't widen the allowlist by mutation. Effect: `http://<hostname>:<port>` (e.g. `codemc:3877`) reaches the tailnet bind. Bind stays the single tailscale v4 — Happy Eyeballs reaches it from IPv6-preferring clients (measured 9ms); never v6/LAN/0.0.0.0.
